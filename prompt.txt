# Na 离子导体研究 — 会话交接（2026-08-17）

## 一、核心目标

**全局目标**：用晶体结构文件里可复算的量，解释并检验 Na 固态离子导体的室温离子电导率，并显式控制体系差异（NASICON / 硫化物 / 卤化物）。成果目标层级是 1 区 Top 与子刊，2 区以下不再考虑。

**本阶段的核心目标只有一句**：

> **在看到任何电导率数据之前，把定义、判据、候选清单全部冻结完。**

这不是准备工作，这是本阶段的全部内容。原因是样本量：分层之后可用观测大约五六十个，任何一个"看到结果之后再决定"的选择都会让结论不可辩护。

**当前阶段的三条子目标**：

1. **确认现有 41 个描述符各自在数学上算的到底是什么量**（不是修 bug，是确认名字与数学是否指同一件事）
2. **把 157 条离散分类候选剪到 5–6 条主检验**，其余降入探索层
3. **数据录入前的最后一批冻结**（体系值域、假设预注册、分类量候选剪枝）

**已钉死的事实（不依赖数据，可写进论文）**：

- 漏斗是 41 条注册 → 38 条进搜索 → 3 条幸存。前一步是代码派生可复核，后一步是三轮人工评审判定，性质不同不可写成一个漏斗

## 四、数据线现状

**数据集不存在。** 用户正在并行搭建，与算法线同时进行。

**数据契约已冻结**：两张表（材料 12 列、测量 15 列）、只读校验器、七条确定性室温取值规则。主要观测量是总电导，体相电导仅作敏感性（理由：体相的定义随等效电路而变，跨文献不可比）。

**仍待填**：`system` / `system_coarse` 的值域，以及四条用法决定（两级映射表要不要冻结、残差化默认用哪一级、n=1 的小组怎么处理、遇到未见体系怎么办）。这是契约第一版的最后一次修订窗口。

**最大单点风险**：跨文献总电导在数量级上受相对致密度和晶界支配，而致密度与体系不共线、残差化控不掉。那一列的缺失率决定路线走向，录完才知道。

**工具限制**：键价能量计算的二进制在远程服务器上，本地跑不了。`bvse_barrier_estimate` 无条件返回空值。可用 `bvlain`（纯 Python，直接输出按方向分的贯通势垒）替代。

## 五、论文线现状

**层级判断（已核实文献）**：

- 顶刊与 2–3 区的差别不在机器学习更强，而在四处：标签自造而非抄文献、量是先验推出而非搜出、证据链终点是前瞻验证、结论可被他人拿去用
- **两个原定卖点已被占**：Sendek 2017 的摘要就是"单个描述符不够、需多描述符组合"；Na 体系已有 3573 个 NASICON 结构的分类筛选（准确率 84.2%）。所以"缺乏综合描述符"和"尚无清晰阈值"两句立论都不成立
- **真正的空白**是 npj 2024 自己写下的：现有做法找的是电导与通道尺寸、配位数之类的显式相关，有漏掉超离子导体的风险，而机制层面的关键描述符尚未揭示。**这个空白正好落在你手上的审计资产上**
- 纯计算路线的天花板是 npj Computational Materials 层级（在目标集合内）；Nature Materials 需要合成实测，不可达

**候选筛选的四道关**（顺序固定，全程不看电导率）：

1. 能否写出"若某一类更好，化学家该做什么"，且动作是可执行的合成操作
2. 同一体系内部是否有类别差异（否则会被体系标签吃掉）
3. 参数扫描下结论是否稳定 + 至少两种合理构造的一致率
4. 用实际数据算不算得出

**现有 8 条候选池**（5 原有 + 3 补充），全部只过了第一、四关的粗估：

| 候选 | 说的是什么 |
|---|---|
| 通道方向的贯通顺序 | 放宽通道门槛时，网络先在一个方向连通、再两个、再三个的次序 |
| 长程路径是否必须换配位环境 | 走完一条长程路是否必须经过配位数不同的位点 |
| 关键通道上多面体是共顶点还是共棱共面 | Ceder 那条锂的规则换到钠上 |
| 关键瓶颈是唯一还是并列多条 | 一个缺陷会不会直接断路 |
| 钠通道维度与骨架维度是否匹配 | 迁移网络维度不能超过骨架允许的维度 |
| 周期路径的对称族冗余 | 删掉整类对称等价的通道后是否还连通 |
| 笼与窗口的净空剖面 | 通道是均匀的、还是单一大瓶颈、还是多级收缩 |
| 关键窗口的化学组成顺序 | 瓶颈周围的元素排列是单一、交替还是分块 |

**统计设计**：主检验 5–6 条，各自算有效边际 p 值后用全局校正控制假阳性；其余 130 多条进探索层，只写"值得后续检验"。置换必须保持体系、材料、来源的可交换性。

**能立刻接进流程的两层（现在完全没有）**：

- **质量与资格标签**（约 5 条，只要坐标和晶格）：两种配位算法是否一致、空间群随对称容差是否稳定、报告的无序类型、占据位与空隙位的对应关系、临界通道枚举是否稳定。作用是决定某条结构对某个候选是否合格，不参与相关性检验
- **负对照基线**（约 5 条）：空间群号、晶胞原子数、Wyckoff 位置数等。作用是要求新候选必须比它们多提供信息

**要新写的只有一件**：分类量的检验分支。现有管线是"连续量 → 秩相关 → 去混杂"，新候选全是分类量，用不上这条路。需要组间比较、效应量与置信区间、精确置换、体系分层。精确置换那部分已有实现。

## 七、协作方式

- **评审输出用"亮点 / 弊端"结构**，弊端走拒稿视角，不写鼓励性框架；结论用表格给判定
- **审计报告直接作为回复正文，不生成文件**
- 给执行器的 prompt 一律自足（背景、环境、边界都写全，行号须自行核实），一次排多项，把清账类杂项一次排完
- 回复要短，避免夹杂英文术语，要照顾不精通机器学习的读者
- 期刊评价用中科院分区（大类 + Top），分区层级与实质判断分开陈述

**已踩过的坑（十条，按性质归三类）**：

*执行器侧*：用推断代替执行、用叙述代替命令输出、结论的产物跑完就删、贴出推翻自己上一轮说法的证据却不指出、把冲突节当免责声明

*评审侧（我犯的）*：用执行器自述代替源码核实，把不存在的问题升为最高优先级

*prompt 侧*：互斥指令并存、让分析表去和检索命中数对账

*工具侧*：产物同名覆盖、Windows 编码把"不一致"截断显示成"一致"导致误判

**四条会话提醒**：

1. 验收会自我延续。若剩下的问题都是文档级、不改变行为，就该封版
2. 等待期容易被可做的事填满。排下一步先问"这件事让待填数减少了吗"
3. 判据的极性要单独检查一遍 —— 有一次规则写对了六个维度、第七个反了，而它恰好最关键
4. 任何"被掩盖/不存在"的结论必须索取源码，不能采信自述
